# Unity skills

Skills bound to the Unity / Walnut bench. They assume its apps, sites and team process, so they are
not part of the general set.

Source: https://github.com/UnityAppSuite/unity_dev_tools (`skills/`). Nothing has been copied yet.

## Candidates to move here

| Skill in unity_dev_tools | What it does | Why it is Unity-specific |
|---|---|---|
| `depmap` | Cross-app dependency map of the Unity bench | Reads the Unity app list and `~/frappe-bench/apps/` |
| `graphify` | Internals of Unity / Walnut apps: functions, hooks, controllers | Built on the Unity app graph |
| `uat-employee-seeder` | Seeds test Employees on a Walnut UAT site | Walnut site, Google Workspace toggle |
| `uat-prod-deploy-comparison` | UAT versus production deploy comparison | Unity repos and release flow; the general version is `deploy-notes-comparison` |
| `unity-edu-fwd` | Unity Edu forwarding workflow | Unity Edu process |
| `unity-email-drafter` | Email drafting in the Unity Edu voice | Unity Edu team |
| `project-update` | Weekly update for the Project Update DocType | Unity Edu DocType |
| `timesheet-suite` | Timesheet reporting | Unity Edu HR setup |
| `manager-work-report` | Manager work report | Unity Edu process |
| `project-charter`, `project-plan-manager` | Project charter and plan | Unity Edu templates |
| `doc-request-helper` | Document request helper | Unity Edu process |
